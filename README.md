# Prasenjit Online Shop

A simple, responsive e-commerce web application. This project is for web development practice, portfolio and college/project work.

## Features
- Product listing with categories
- Search & filter
- Shopping cart & checkout UI
- User login / registration
- Admin panel to add/edit products
- Responsive design (mobile friendly)

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript / React
- Backend: Node.js + Express / or PHP
- Database: MongoDB / MySQL
- Hosting: GitHub Pages / Vercel

## How to Run Locally
1. Clone the repo
   git clone https://github.com/kalimata352-blip/Prasenjit-online-shop-.git
2. Open `index.html` in browser
   OR if using Node.js:
   npm install
   npm start
